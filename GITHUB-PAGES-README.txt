پگو | pego - بسته آماده انتشار در GitHub Pages

۱) تمام محتویات این پوشه را در ریشه Repository گیت‌هاب قرار بده.
۲) مطمئن شو index.html مستقیماً در ریشه Repository است.
۳) در GitHub وارد Settings > Pages شو.
۴) در بخش Build and deployment گزینه Deploy from a branch را انتخاب کن.
۵) Branch را روی main و Folder را روی /(root) بگذار و Save کن.
۶) بعد از انتشار، آدرس https://USERNAME.github.io/REPOSITORY/ خواهد بود.

این نسخه فقط فرانت‌اند استاتیک است. برای قیمت، موجودی، ورود، سفارش و پرداخت واقعی، بک‌اند Django باید جداگانه روی یک سرور منتشر و API آن به فرانت‌اند متصل شود.
